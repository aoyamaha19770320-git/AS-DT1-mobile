# AS-DT1 Mobile（Android版Chromeで動く AS-DT1 計測・記録アプリ）

公開ページ: https://aoyamaha19770320-git.github.io/AS-DT1-mobile/ （Androidの Chrome で開く）
アプリ本体は `index.html`（単一ファイル）。PC用の変換スクリプトは `tools/asdt1_convert.py`。

Sony AS-DT1 を **スマホ（Galaxy A25 / Android）にUSB-Cで直結** し、
距離画像・3D・断面を表示しながら、点群＋IMU＋GPS を1つのファイルに記録します。
アプリのインストールは不要で、Chromeで `asdt1_mobile.html` を開くだけです。

```
  AS-DT1 ──USB-C──▶ スマホ(Chrome)                 PC
   点群・IMU         ├ 距離画像 / 3D / 断面            │
                     ├ 記録 (.asdt1 = 点群+IMU+GPS+メモ)│
                     └ 保存/共有 ─────────────▶ asdt1_convert.py
                                                 ├ ply/frame_0001.ply … (lidar-viewer互換)
                                                 ├ times.csv (時刻台帳) / track.gpx
                                                 ├ imu.csv / markers.csv
                                                 └ frames.npz (解析用)
```

## 1. 初回の準備（5分）

| 手順 | 内容 |
|---|---|
| ① ケーブル | USB-C ⇔ USB-C（データ対応）。AS-DT1は **5V 500mA（2.5W）** を要求。スマホ直結で動かない場合は「PD対応USB-Cハブ＋モバイルバッテリー」を間に入れる（§5） |
| ② 公開場所 | `asdt1_mobile.html` を **https のページ** として開く必要がある（GitHub Pages が簡単・無料）。ローカルファイル（`file:///sdcard/Download/asdt1_mobile.html`）でも動くことがある |
| ③ 動作モード | AS-DT1 本体が **CDCモード** であること（PCの lidar-viewer で使えていれば既にCDC）。違う場合はアプリが案内を出し、ボタン1つで切替可能 |

## 2. 画面の使い方

```
 ┌───────────────────────────────┐
 │ AS-DT1 Mobile   [USB 計測中][30M15F][GPS ±4m][REC] │ ← 状態
 ├───────────────────────────────┤
 │ コマ/秒 15.0 | 有効点 94% | 距離中央値 6.5m | 温度 31℃  │
 │ 距離範囲 3-15m | 見下ろし角 38° | 記録 1234コマ | GPS精度 │
 │ ┌───────────────────────────┐ │
 │ │   距離画像（24×24、色＝距離）     │ │ ← タップで座標
 │ └───────────────────────────┘ │
 ├───────────────────────────────┤
 │ [接続] [計測開始] [● 記録]             │ ← 操作
 │ [1コマ撮影] [マーカー] [設定]           │
 ├───────────────────────────────┤
 │ 距離画像 | 3D | 断面 | 情報 | 記録 | ログ │ ← タブ
 └───────────────────────────────┘
```

1. **接続** → Chromeの機器選択で「AS-DT1」を選ぶ（初回のみ権限確認）
2. **計測開始** → 距離画像が動く（15コマ/秒。30M15F）
3. **● 記録** → ブラウザ内に溜まる（5秒ごとに書き込み。途中で切れてもそこまで残る）
4. **マーカー** → 距離標の通過・区間の始まり終わり・較正ショットなどを時刻＋GPS付きで記録
5. **■ 記録停止** → 「記録」タブで **保存**（ダウンロード）または **共有**（Drive / OneDrive アプリへ）

| タブ | 見えるもの |
|---|---|
| 距離画像 | Sonyの2Dビューアと同じ配置。灰色＝測れていない点。白い点＝第2反射を使った点 |
| 3D | 点群（右＝+x、上＝+y、前＝+z）。ドラッグで回転、2本指で拡大 |
| 断面 | 側面図（横＝前方距離、縦＝上下）。草面が斜めの一枚面に見えれば構えは良好 |
| 情報 | 製造番号・ファーム版・USB速度・給電（ustatus）・自己診断。コマンドを直接送る欄あり |
| 記録 | 端末内の記録一覧。保存／共有／CSV要約／GPX／削除 |
| ログ | 不具合時はコピーして共有 |

## 3. 設定（⚙）

| 項目 | 既定 | 説明 |
|---|---|---|
| 測定レンジ | 機器の現在値 | 30M15F 推奨（屋外・30m）。変更すると本体が再起動→自動再接続 |
| 連続計測の間隔 | 最速 | 15 or 30コマ/秒。データ量を減らしたいときは 200ms 等 |
| IMUも記録 | ON | 加速度・角速度（100Hz）。**取付角（見下ろし角）の推定に使える** |
| GPSを記録 | ON | スマホのGPS。各コマと同じ時計で記録されるので時刻合わせ不要 |
| 画面を消さない | ON | 記録中の画面消灯（前回GPSが間引かれた原因）を防ぐ |
| 第2反射を使う | ON | 表示のみ。記録は常に生データ（両方の反射） |
| 模擬センサー | OFF | 機器なしで画面を試す。`?sim` を付けて開いても同じ |
| 並び替え表を反転 | OFF | 距離画像の行並びが不自然なときの検証用（§6） |

## 4. PCでの変換

```
pip install numpy
python asdt1_convert.py REC001_20261105_093000.asdt1
```
→ `REC001_20261105_093000/` に `ply/`・`times.csv`・`track.gpx`・`imu.csv`・`markers.csv`・`frames.npz`・`summary.json`

* `ply/frame_NNNN.ply` は lidar-viewer と同じ座標系（x右・y下・z前、mm、無効点 0 0 0）。既存の後処理（pipeline.py）にそのまま渡せる
* `times.csv` の `host_epoch_ms` がスマホ時計（＝GPSと同じ時計）。**時計差の推定は不要**
* `frames.npz` は解析用（センサ座標系 X下・Y左・Z前 と、カメラ座標系の両方）

## 5. 現場リグの推奨

```
  [モバイルバッテリー] ──USB-C PD──▶ [PD対応USB-Cハブ] ──▶ スマホ（充電しながら）
                                          └──USB-A/C──▶ AS-DT1（5V 500mA）
```
* スマホ単体のOTG給電は 500mA 前後が上限で、AS-DT1 の要求（最大2.5W）と同じ水準＝ぎりぎり。長時間はハブ給電が安全
* 「情報」タブの **USB給電状態（ustatus）** に、相手側が出せる電流（Default / 1.5A / 3.0A）が表示される
* センサ温度は「距離画像」タブに常時表示（70℃以下で運用）

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 機器選択に AS-DT1 が出ない | OTG対応ケーブルか／給電不足（ハブを使う）／本体LEDが点滅しているか |
| 「インターフェース確保に失敗」 | 他のアプリがUSBを掴んでいる→スマホ再起動。改善しなければログを共有 |
| 動作モードが「Update」等 | 画面の案内ボタンで CDC に切替（flstart cdc → 再起動） |
| 距離画像の行が縞状・不自然 | 設定「並び替え表を反転」を試す。自然な方を使う。**記録データは影響を受けない**（生データ保存のため、変換時に `--flip-table` で同じ切替が可能） |
| USB接続が切れる | 記録はそこまで保存済み。「接続」を押し直す |
| 保存/共有できない | Chromeのダウンロード許可／空き容量。「記録」タブで容量を確認 |

## 7. 仕様メモ（根拠）
* 通信: USB CDC-ACM（VID 054C / PID 0FC4）、テキストコマンド（`t`, `fsync`, `format binary imu`, `mpinfo`, `svminfo` 等）
* 点群: 1点15バイト（20bit×6: 第1/第2反射の XYZ、0.25mm単位）。展開式は Sony SDK（as_dt1_api_pcd.py）と一致することを乱数検証済み
* 並び替え: 計測出力順→画像順の表は Sony SDK `_MPDATATBL` とAPIマニュアル p.11 の表（同値）を採用
* IMU: 16バイト/レコード（加速度 ±4G, 角速度 ±500dps, 温度, 1µsカウンタ）、約10ms間隔
* 時刻: 各コマに「スマホ時計(ms)」「本体CPU時計 tm」「タイムスタンプ ts」を併記
